# Overview

Building an app that will play both podcasts and audiobook files. App is for android only. App should be minimally light, without feature bloat, so it is quick and responsive. App will be developed piece by piece, and architecture should be modular so that new features can be easily added and removed.

# Environment

Must first set up appropriate environment for developing android app.
All files should be in a github repo.
Begin work to register app for google play store.

# Capabilities

## Podcasts

Get podcasts from RSS feeds, download and store them locally in human readable formats.
Downloads art for podcasts and individual episodes.
Downloads show notes, and has the ability to navigate linked timestamps and embedded sections from the show notes.

## Audiobooks
Plays m4b and collections of mp3 files. 
Reads files for metadata and displays book covers
Ability to set bookmarks in files for later review
Audiobooks can be sourced from either local files or an audiobookshelf server.

## Playback
Ability to adjust playback speed globally and for individual files/media types (podcasts vs. audiobooks)
Ability to 'trim silence' from files during playback
Can boost volume of files.
Sleep timer that can be set for a time duration or file duration (end of episode, end of chapter, etc)
Play history is tracked.

## Playlists
Allow for creation of playlists of mixed podcasts and audiobooks. Allow for automatically inserting files into playlists (e.g. new podcasts go to top or bottom of list)

## Transcripts
Can we Auto transcribe files? Is this something phones can do? (paywall feature)

## Ad removal
Look into auto removing ads from podcasts (paywall feature)

# Ui
To be developed after baseline functionality. It should be modular and easy to iterate upon.
